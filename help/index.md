# Help

You can navigate this website with some vim-style key bindings.

|                           |                              |
| ------------------------- | ---------------------------- |
| <kbd>j</kbd>              | scroll down a line           |
| <kbd>k</kbd>              | scroll up a line             |
| <kbd>G</kbd>              | scroll to the bottom of page |
| <kbd>g</kbd> <kbd>g</kbd> | scroll to the top of page    |
|                           |                              |
| <kbd>h</kbd>              | open _home_ page             |
| <kbd>r</kbd>              | open _resume_ page           |
| <kbd>p</kbd>              | open _projects_ page         |
| <kbd>b</kbd>              | open _blog_                  |
| <kbd>c</kbd>              | open _contact_ page          |
| <kbd>?</kbd>              | open (this) _help_ page      |

Also <kbd>⇥</kbd> and <kbd>⏎</kbd> are your friend for _on page_ navigation.
