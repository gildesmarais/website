# Maintenance Guide

This document outlines key maintenance procedures for the Astro website.

## Movie Data Management

The website uses two main data files for movie functionality:

- `src/data/movies.json`: Contains detailed movie information (titles, ratings, IMDb IDs, etc.) - **single source of truth**
- `src/data/recommendations.json`: Contains movie recommendations with notes

### Updating Movie Data

**Current Process:**

1. **Movies Data**: The `src/data/movies.json` file is generated from a `ratings.csv` file using the migration script:

   ```bash
   bin/migrate-ratings
   ```

   - This script expects `ratings.csv` to be in the project root directory
   - It generates `src/data/movies.json` with detailed movie information
   - The script only processes the CSV file and does not handle recommendations

2. **Recommendations Data**: The `src/data/recommendations.json` file is manually maintained and contains:
   - Movie IMDb IDs (`const` field)
   - Recommendation notes (`note` field)
   - This file is not generated by the migration script

**To update movie data:**

1. Ensure you have the latest `ratings.csv` file in the project root
2. Run the migration script: `bin/migrate-ratings`
3. Manually update `src/data/recommendations.json` as needed
4. Restart the development server if running: `npm run dev`

**Note**: The migration script generates `movies.json` from `ratings.csv`. The `recommendations.json` file requires manual maintenance. All movie ratings are now stored in `movies.json` as the single source of truth.

**Performance**: Recommendation data is cached server-side for optimal performance. The cache is automatically rebuilt when the server restarts.
