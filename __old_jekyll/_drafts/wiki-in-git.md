# the problem

having snippets and notes spread on different devices and apps.
code snippets in dash
some notes in simplenote

con: not the owner of the data.

# my solution

use a file based wiki which supports markdown.

pros:

- use of Makefile, prettier, etc (formats code in your markdown file, yay)
- git based means: there's a change history for each file

cons:

- unencrypted storage
- unsolved: need to manually commit and push changes made on mobile
- gollum does not support tagging files
